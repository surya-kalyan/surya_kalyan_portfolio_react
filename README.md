# Surya Kalyan Portfolio - React Version

A modern, animated React portfolio website for Surya Kalyan B, showcasing his expertise in AI development and data science.

## Features

- **Modern React Architecture**: Built with React 18 and functional components
- **Smooth Animations**: Powered by Framer Motion for engaging user experience
- **Intersection Observer**: Animations trigger when sections come into view
- **Responsive Design**: Fully responsive across all device sizes
- **Component-Based**: Modular structure for easy maintenance
- **Performance Optimized**: Efficient rendering and animation performance

## Technologies Used

- React 18
- Framer Motion (animations)
- React Intersection Observer
- CSS3 with modern features
- Responsive Grid Layout

## Installation

1. Navigate to the portfolio-react folder:
```bash
cd portfolio-react
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Animation Features

- **Staggered Animations**: Sequential element animations for smooth flow
- **Hover Effects**: Interactive hover animations on cards and buttons
- **Scroll-Triggered**: Animations activate when sections enter viewport
- **Smooth Transitions**: Fluid transitions between states
- **Performance Optimized**: Hardware-accelerated animations

## Available Scripts

- `npm start` - Runs the app in development mode
- `npm build` - Builds the app for production
- `npm test` - Launches the test runner
- `npm eject` - Ejects from Create React App (one-way operation)

## Deployment

To build for production:

```bash
npm run build
```

This creates a `build` folder with optimized production files ready for deployment.
